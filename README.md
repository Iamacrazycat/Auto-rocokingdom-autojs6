# Auto-RocoKingdom-AutoJS6

基于 **AutoJS6** 开发的《洛克王国》手机端全自动挂机助手。本项目利用 OpenCV 进行图像模板匹配，实现自动识别游戏状态并执行对应策略（如遇到污染精灵自动聚能，非污染精灵自动逃跑）。

欢迎提交 Issue 反馈 Bug 或提供新功能建议。由于设备限制，目前仅在一台手机上进行了测试，若在其他分辨率下遇到适配问题，也欢迎提报！

## 🎯 核心功能

- **🔥 聚能模式**：无差别聚能，只要进入战斗状态即执行聚能操作。
- **💨 逃跑模式**：无差别逃跑，进入战斗状态即执行逃跑操作。
- **🧠 智能模式**：智能识别目标，遇到“污染精灵”自动聚能，遇到“非污染精灵”则自动逃跑。
- **🛠️ 攻击模式**：支持用户录入自定义攻击坐标 X/Y。在战斗中，第一回合先攻击一次自定义位置，后续回合可选择“聚能”或“重复攻击”。支持设置检测到捕捉按钮可用（红标消失）时，自动转为聚能（停止攻击）。[如何录入坐标](#attack-mode-guide)

## 🔧 实现细节

核心逻辑基于**状态机轮询**，每隔几秒截屏并进行模板匹配。根据匹配结果，将游戏划分为四种状态：`非战斗模式`、`污染精灵`、`非污染精灵` 和 `其他`。

**状态保持机制：**  
当进入战斗模式时，系统会回溯并锁定上一次的状态记录。例如，若上一次状态为“污染精灵”，则整场战斗都会延续聚能策略；只有在“非战斗状态”下才会重新进行模板匹配。
这一设计不仅优化了性能，最重要的是确保了**单场战斗策略的一致性**，避免了因“污染精灵”褪色或特效遮挡导致的中途误判（如突然自动逃跑）。

> _关于模板匹配的详细图像素材，请参阅 `templates` 文件夹。_

## 🚀 快速开始

### 方法 A：直接下载安装（推荐）

1. 前往 [Releases](../../releases) 页面下载最新的 **APK 安装包**。
2. 安装并启动 App，按照下方的 **“配置与启动”** 步骤操作即可。

### 方法 B：通过 AutoJS6 运行源码

1. 安装 [AutoJS6](https://github.com/SuperMonster003/AutoJs6/releases) 客户端。
2. 将本项目源码文件夹整体拷贝至手机目录（例如 `/sdcard/脚本/AutoRoco/`）。
3. 在 AutoJS6 中找到并运行 `main.js`。

## ⚙️ 配置与启动

1. **权限授权**：在主界面点击 **“开启无障碍服务”** 和 **“开启悬浮窗权限”** 完成系统授权。
2. **参数配置**：根据需要调整参数（默认参数已针对主流配置优化），调整完毕后点击 **“保存配置”**。
3. **启动挂机**：选择运行模式（聚能 / 逃跑 / 智能 / 攻击），点击 **“启动脚本”**。
4. **悬浮窗控制**：脚本运行中，屏幕会显示半透明悬浮窗。
   - 点击 **“暂停”** 以便进行手动操作。
   - 点击 **“继续”** 恢复自动挂机。
   - 点击 **“关闭”** 彻底终止脚本。

## 📐 <a id="attack-mode-guide"></a>测量自定义坐标说明

当您使用**攻击模式**时，需要录入技能或攻击按钮的 X 和 Y 物理像素坐标。您可以通过以下步骤来轻松测量：

1. **开启开发者模式**：
   - 打开手机的 **系统设置** -> **关于手机** (或 **我的设备**)。
   - 连续快速点击 **版本号** (例如编译版本号、系统版本号等) 5 - 7 次，直到系统提示 `“您已处于开发者模式”`。
2. **启用指针位置显示**：
   - 返回设置主页，找到并进入 **系统和更新** -> **开发者选项** (部分手机在“其他设置”或“更多设置”中)。
   - 往下滑动找到并开启 **“指针位置”** (Pointer Location) 开关。
3. **获取坐标数值**：
   - 打开游戏，进入战斗状态。
   - 用手指触摸或点击您想要录入的按钮中心位置，此时屏幕顶部会显示一条十字准星，同时最上方状态栏会显示当前触摸点的详细坐标。
   - 记录其中 `X:` 和 `Y:` 后面显示的数值（例如 `X: 2345`，`Y: 960`），并将其填入挂机助手的 **“攻击模式配置”** 中。
   - 测量完成后，可返回开发者选项关闭“指针位置”以清除屏幕痕迹。
