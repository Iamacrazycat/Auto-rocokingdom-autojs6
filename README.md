# Auto-rocokingdom-autojs6

本项目是基于 **AutoJS6** 与 **OpenCV** 开发的《洛克王国》手机端全自动挂机助手。采用观察者模式与状态机逻辑，通过 HSV 特征过滤实现高精度的战斗识别与自动化操作。

> [!TIP]
> 💡 **灵感来源**：[yorusacri/Auto-rocokingdom](https://github.com/yorusacri/Auto-rocokingdom)  
> 📚 **AutoJS6 官方文档**：[docs.autojs6.com](https://docs.autojs6.com/#/)
> 📄 **更新记录**：[查看详细更新日志 (CHANGELOG)](CHANGELOG.md)

---

## 🎯 核心功能

*   **🚀 状态机观察者模式**：每隔数秒自动捕获屏幕并判定当前游戏状态（非战斗、有效战斗、无效战斗）。通过“向上追溯”逻辑确保在画面过渡时战斗计数器的稳定性。
*   **👁️ OpenCV 高精识别**：完全摒弃 OCR，采用多比例缩放模板匹配。引入 **HSV 颜色空间过滤**，可精准区分极度相似的“捕捉”与“放弃捕捉”界面。
*   **🎨 原生可视化 UI**：
    *   **权限引导**：一键检查并跳转开启无障碍服务与悬浮窗权限。
    *   **参数配置**：支持轮询间隔、匹配阈值、参考分辨率等参数的实时修改与本地持久化保存。
*   **🖱️ 交互式悬浮窗**：
    *   **运行/暂停**：支持在不关闭脚本的情况下随时暂停挂机，方便手动干预。
    *   **自由拖拽**：悬浮窗位置随心而定，不遮挡游戏关键 UI。
*   **⚡ 性能优化**：
    *   **坐标缓存**：关键点击按钮实现“一次匹配，永久缓存”，大幅降低 CPU 负载。
    *   **自适应缩放**：自动适配各种异形屏与主流分辨率（基准 2772x1280）。

## 🚀 快速开始

### 方法 A：直接下载安装（推荐）
1.  前往 [Releases](../../releases) 页面下载最新的 **APK 安装包**。
2.  安装并启动 App，按照下方“配置与启动”步骤操作即可。

### 方法 B：通过 AutoJS6 运行源码
1.  安装 [AutoJS6](https://github.com/SuperMonster003/AutoJs6/releases) 客户端。
2.  将本项目源码文件夹整体拷贝至手机目录（如 `/sdcard/脚本/AutoRoco/`）。
3.  在 AutoJS6 中找到并运行 `main.js`。

### ⚙️ 配置与启动
1.  在主界面点击 **“开启无障碍服务”** 和 **“开启悬浮窗权限”** 按钮进行授权。
2.  根据需要调整参数（默认已针对主流配置优化），点击 **“保存配置”**。
3.  选择运行模式（聚能/逃跑/智能），点击 **“启动脚本”**。
4.  **挂机中操作**：屏幕出现半透明悬浮窗，可点击 **“暂停”** 手动操作，点击 **“继续”** 恢复，点击 **“关闭”** 终止。
